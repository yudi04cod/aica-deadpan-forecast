A deadpan weather forecast for Glintwick, a city that does not exist: a high of 41, a 70% chance of rain falling upwards again, and the mayor asking residents to hold their umbrellas upside down. Absurd, but delivered like a straight-faced TV meteorologist reading it off the map.

## Run it

```sh
python3 main.py
```

Writes one line (141 characters) to `/output/entry.txt`. Python standard library only, deterministic — byte-identical on every run.
